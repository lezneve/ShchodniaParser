# ShchodniaParser

пошук товарів і знижок у мережі «щодня», з термінала.

невеликий python-скрипт: вибираєш магазин, шукаєш товар або скануєш каталог на знижки. окремий скрипт зберігає каталог у локальну базу sqlite. скрипти ходять у мережу (api мобільного застосунку «щодня»): без цього вони не працюють.

лише код, без релізів. MIT.

## запуск

потрібен [uv](https://docs.astral.sh/uv/). запускати з кореня репозиторію.

```sh
uv run --with aiohttp --with requests shchodnya_parser.py
```

## меню

| пункт | що робить |
| --- | --- |
| 1 | пошук товару за штрихкодом, артикулом або назвою: ціна, знижка, артикул, штрихкод, категорія, статус |
| 2 | сканування каталогу вибраного магазину на знижки |
| 3 | змінити магазин (за містом або вулицею) |
| 0 | вихід |

під час першого запуску скрипт просить вибрати магазин. якщо точного збігу за штрихкодом чи артикулом немає, показується найближчий результат пошуку, з позначкою про це.

сканування проходить каталог сторінками по 100 товарів у 15 потоків і показує один рядок прогресу. наприкінці: скільки товарів перевірено з усього каталогу і таблиця з 20 найбільшими знижками. сторінки, на які після трьох спроб немає відповіді, перелічуються в підсумку. колір вимикається змінною `NO_COLOR` і сам вимикається, коли вивід не в термінал.

## дамп каталогу

```sh
uv run --with aiohttp --with requests dumper_shchodnya.py
```

записує весь каталог (без прив'язки до магазину) у таблицю `products` файлу `shchodnya.sqlite` у поточному каталозі. таблиця створюється сама; повторний запуск оновлює рядки за `id`. наприкінці показує, скільки товарів збережено і за який час.

## структура

| файл | що в ньому |
| --- | --- |
| `shchodnya_parser.py` | меню, пошук, вивід |
| `shchodnya_api.py` | запити до api, моделі магазину й товару, обхід каталогу |
| `dumper_shchodnya.py` | дамп каталогу в sqlite |
| `common.py` | конфіг, запити з повтором, рядок прогресу, таблиця |

## налаштування

`config_shchodnya.json` створюється сам після вибору магазину: id і адреса магазину. він локальний і в репозиторій не входить, як і `shchodnya.sqlite`.

інших налаштувань немає: ні ключів, ні `.env`.

## обмеження

не перевірено, тому не обіцяється:

- що api «щодня» відповідає так само, як тоді, коли писався код. скрипт залежить від його адрес і формату відповіді; коли вони зміняться, він перестане працювати
- автоматичних тестів немає

відомо:

- `pyproject.toml` немає: залежності (`aiohttp`, `requests`) передаються через `uv run --with`
- сканування й дамп запитують усі сторінки каталогу без пауз, лише з обмеженням у 15 потоків
