# ShchodniaParser

## що це

термінальний скрипт для пошуку товарів і знижок у мережі «щодня». працює з api мобільного застосунку й може зберегти каталог у локальну базу sqlite.

скрипт ходить у мережу: до api «щодня».

## запуск

потрібен [uv](https://docs.astral.sh/uv/). запускати з кореня репозиторію.

```sh
uv run --with aiohttp --with requests shchodnya_parser.py
```

у меню: вибір магазину за містом або вулицею, пошук товару за штрихкодом, артикулом чи назвою, сканування каталогу з таблицею найбільших знижок. магазин зберігається в `config_shchodnya.json`.

сканування показує один рядок прогресу. сторінки, на які після трьох спроб немає відповіді, перелічуються в підсумку. колір вимикається змінною `NO_COLOR`.

### дамп каталогу

```sh
uv run --with aiohttp --with requests dumper_shchodnya.py
```

записує товари в таблицю `products` файлу `shchodnya.sqlite` у поточному каталозі.

## структура

| файл | що в ньому |
| --- | --- |
| `shchodnya_parser.py` | меню, пошук, вивід |
| `shchodnya_api.py` | запити до api, моделі магазину й товару, обхід каталогу |
| `dumper_shchodnya.py` | дамп каталогу в sqlite |
| `common.py` | конфіг, запити з повтором, рядок прогресу, таблиця |
